# Security policy

Security fixes target the latest released version. No response-time guarantee is
provided. The card uses the logged-in Home Assistant user's permissions and does
not store credentials or send telemetry.

Please do not disclose a suspected vulnerability in a public issue. Use the
repository's **Security → Advisories → Report a vulnerability** feature when
private vulnerability reporting is enabled. If that option is not available,
ask the maintainer for a private reporting channel without publishing details.

Never include access tokens, camera credentials, private URLs, full configuration
directories or unredacted logs in reports. Browser-side motion-stop commands are
best effort and are not a hardware safety control.
