# PTZ Control Card 0.1.1

Fix preset and center buttons incorrectly disabled for command-style preset entities.

## Fix

Some camera integrations expose selectable preset options while reporting the
current preset as `unknown`. Version 0.1.0 treated that state as unavailable,
disabling both the preset buttons and preset center action.

Select/input-select entities with state `unknown` now remain usable when they
provide a non-empty `options` list. A known current camera position is not
required to send a preset command.

## Preserved checks

- Missing or `unavailable` entities remain disabled, even with cached options.
- Unknown preset entities without options remain disabled.
- A fixed `center_preset` must exactly match an available option. Invalid fixed
  targets still disable only the center button; valid preset buttons remain usable.
- Zoom availability and motion-stop handling are unchanged.

## Validation and update

- 41 automated tests passed, including six new preset regression cases.
- ESLint, release-tagged build and dependency audit passed; no vulnerabilities
  were reported at check time.
- Update through Marketplace/HACS, then reload the browser to load the new card.
  If the old behavior persists, clear the browser's frontend cache.
- No configuration change is required for this fix. Independently check that a
  configured `center_preset` actually exists in the select entity's options.

Real-device behavior after this update still needs confirmation. Browser-side
stop commands remain best effort, not a safety guarantee.
