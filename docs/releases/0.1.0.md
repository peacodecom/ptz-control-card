# PTZ Control Card 0.1.0

Initial standalone release of the existing PTZ dashboard card.

## Features

- Circular pan/tilt controls, hold-to-move and single-press modes.
- Best-effort release/cancel/focus/visibility/disconnect stop handling.
- Optional preset selection and center recall action.
- Optional zoom slider and absolute/percentage button increments.
- Configurable colors/icons, responsive layout and keyboard controls.
- Support for button/script entities and select/number helpers.

## Hardening and distribution

- Entity-domain validation, escaped text/attributes and safe CSS property assignment.
- Preserved active movement handlers during Home Assistant state updates.
- Sequenced preset selection before go actions; handled service errors.
- English/German docs with Marketplace and legacy HACS installation, complete
  option tables and an example script-driven heating-panel navigation pad.
- Automated tests, CI and a single-file Marketplace/HACS release asset.
- MIT license, copyright 2026 Norman Bauer; published by peacode.

## Requirements and limitations

- Existing movement entities or scripts from a Home Assistant integration.
- Current browser with ES2022 and Pointer Events support.
- YAML configuration; no graphical editor, camera video or ONVIF connection.
- Stop delivery cannot be guaranteed during browser, network or device failure.
- Local preparation: 35 automated tests passed; ESLint and release-tagged build
  passed; no dependency vulnerabilities reported at check time. See the
  [validation record](../validation.md).
- Real-camera/browser validation and a Marketplace/HACS
  installation check must be recorded by the maintainer before announcing the release.
